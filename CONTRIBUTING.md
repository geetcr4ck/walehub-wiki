# Cara Nambah Link (Tanpa Git, Lewat Web Saja)

Buat admin yang tidak paham git atau PR, cukup pakai browser.

## Edit via github.com

1. Buka repo `geetcr4ck/walehub-wiki` di github.com.
2. Masuk ke folder `docs`, lalu buka file yang sesuai: `tools.md`, `adblocking.md`, `dns.md`, `keamanan.md`, `ai.md`, `audio-ai.md`, atau `gaming.md`.
3. Tekan ikon pensil (Edit this file) di kanan atas.
4. Tambah 1 baris baru di section yang pas, pakai format di bawah.
5. Tekan tombol hijau `Commit changes`, pilih `Commit directly to the main branch`, tekan lagi `Commit changes`. Selesai, situs update sendiri setelah deploy jalan.

## Format 1 baris (copy-paste)

```md
- [Nama Situs](https://contoh.com/) - deskripsi 1 baris jujur tentang gunanya.
```

Kalau ada link GitHub, tambah di sampingnya:

```md
- [Nama Situs](https://contoh.com/) ([GitHub](https://github.com/user/repo)) - deskripsi 1 baris jujur tentang gunanya.
```

## Aturan singkat

1. Cek link masih hidup sebelum ditambah, buka dulu di browser.
2. Deskripsi cukup 1 baris, jujur, tanpa klaim berlebihan.
3. Cek duplikat dulu pakai search di wiki, jangan tambah link yang sudah ada.

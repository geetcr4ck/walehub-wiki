# AI

Kumpulan tool AI yang kepakai bareng: chatbot gratis, setup ringan, dan trik biar hasilnya maksimal.

## Chatbot

- [DeepSeek](https://chat.deepseek.com/) ([GitHub](https://github.com/deepseek-ai)) - chatbot AI gratis unlimited berbasis DeepSeek-V4.1-Flash yang perlu signup, bisa ditambah fitur via [Better DeepSeek](https://github.com/EdgeTypE/better-deepseek/).
- [Qwen Studio](https://chat.qwen.ai/) ([GitHub](https://github.com/QwenLM)) - chatbot resmi Alibaba berbasis Qwen dengan mode thinking dan agent, multimodal, dan konteks hingga 1M token buat coding, riset, dan dokumen.
- [Z.ai](https://chat.z.ai/) ([GitHub](https://github.com/zai-org)) - chatbot dan agent Zhipu berbasis GLM-5.3/Flash buat coding agentic, visual coding, slides, dan dokumen dengan konteks panjang multimodal.
- [Google AI Studio](https://aistudio.google.com/app/prompts/new_chat) ([Add Features](https://github.com/Nagi-ovo/voyager)) - playground resmi Google buat coba Gemini 3.8 Flash, 3.1 Pro Preview, dan 3.5 Flash-Lite, perlu login Google.
- [Gemini](https://gemini.google.com/) ([Add Features](https://github.com/Nagi-ovo/voyager)) - chatbot resmi Google berbasis Gemini 3.6 Flash, 3.1 Pro Preview, dan 3.5 Flash-Lite buat nulis, riset, dan multimodal.
- [Meta AI](https://www.meta.ai/) - chatbot gratis unlimited berbasis Muse Spark 1.2 dan Muse Glimmer 30B yang perlu login Meta, enak buat tanya cepat dan sosmed.
- [Kimi](https://www.kimi.ai/) ([GitHub](https://github.com/MoonshotAI)) - chatbot Moonshot berbasis Kimi K3 buat dokumen panjang dan slides, bisa login Google atau nomor HP, alternatif di kimi.com.
- [ChatGPT](https://chatgpt.com/) ([Add Features](https://github.com/Nagi-ovo/voyager)) - chatbot OpenAI berbasis GPT-5.6 Luna yang gratis unlimited buat nulis, coding, dan tanya umum.
- [LongCat](https://longcat.ai/chat/) - chatbot gratis unlimited berbasis LongCat 2.0 yang perlu signup, cocok buat ngobrol dan tanya umum.
- [Tencent AI Studio](https://aistudio.tencent.com/) - playground Tencent berbasis Hy3 yang gratis unlimited, perlu signup, pas buat eksperimen model China.
- [MiMo Studio](https://aistudio.xiaomimimo.com/) - playground Xiaomi berbasis MiMo-V2.6-Pro dan MiMo-V2.6 Flash yang perlu signup, enak buat coding dan reasoning.
- [Grok](https://grok.com/) ([Rate Display](https://greasyfork.org/en/scripts/558017)) - chatbot xAI berbasis Grok 4.5 dengan mode agent, limit berbasis traffic, cocok buat info realtime dan tanya santai.
- [Microsoft Copilot](https://copilot.microsoft.com/) - asisten Microsoft berbasis GPT-5.1 dengan Think Deeper yang gratis unlimited, perlu signup, terintegrasi Windows dan Edge.
- [Claude](https://claude.ai/) ([Add Features](https://github.com/Nagi-ovo/voyager) / [Usage Tracker](https://github.com/lugia19/Claude-Usage-Extension)) - chatbot Anthropic berbasis Claude Sonnet 5 yang perlu signup dan kadang verif HP, jago nulis dan coding rapi.
- [Chat Motif](https://chat.motiftech.io/chat) - chatbot gratis unlimited berbasis Motif 3 buat ngobrol dan tanya umum tanpa ribet.
- [MiniMax](https://agent.minimax.io/) ([GitHub](https://github.com/MiniMax-AI/)) - platform agent berbasis MiniMax M3 yang perlu signup, bisa browsing dan eksekusi tugas otomatis.
- [Mistral](https://chat.mistral.ai/) - chatbot Eropa berbasis Mistral Medium 3.5 buat coding dan tanya cepat, ada versi console di console.mistral.ai.
- [Ai2 Playground](https://playground.allenai.org/) - playground Allen AI buat coba Olmo 3.1 32B Think gratis unlimited tanpa signup, open dan transparan.
- [Solar](https://solar-chat.upstage.ai/) - chatbot Upstage berbasis Solar Pro 4 yang bisa dipakai tanpa signup, ringan buat tanya cepat.
- [Solar Playground](https://console.upstage.ai/playground/chat) - versi console playground Upstage buat utak-atik Solar Pro 4 tanpa signup, beda dari Solar chat yang simpel.
- [ArceeAI](https://chat.arcee.ai/chat) - chatbot gratis unlimited berbasis Trinity Large Thinking, kuat di reasoning dan tanya teknis.
- [Sarvam](https://dashboard.sarvam.ai/chat) - chatbot India berbasis Sarvam 105B yang gratis unlimited, perlu signup, jago multibahasa.
- [Poolside](https://chat.poolside.ai/) - chatbot berbasis Laguna S 2.1 dan Laguna XS 2.1 yang fokus ke coding dan workflow developer.
- [Inception](https://chat.inceptionlabs.ai/) - chatbot gratis unlimited berbasis Mercury 2 yang kencang buat tanya cepat dan coding ringan.

## Coding AI

> Catatan: banyak coding AI jalan dengan akses root dan bisa ubah file plus eksekusi perintah terminal, jadi backup kode dulu, jangan kasih akses full drive, dan idealnya jalan di container atau VM.

- [OpenCode](https://opencode.ai/) ([GitHub](https://github.com/anomalyco/opencode) / [Resources](https://github.com/awesome-opencode/awesome-opencode)) - coding AI agent berbasis Muse Spark 1.3 dan MiMo-2.5 yang jalan di terminal dan enak buat ngoding langsung di repo.
- [Aider](https://aider.chat/) ([GitHub](https://github.com/Aider-AI/aider)) - terminal coding agent yang nyambung ke repo Git dan enak buat edit file cepat dari command line.
- [Cline](https://cline.bot/) ([GitHub](https://github.com/cline/cline) / [Zoo Code](https://github.com/Zoo-Code-Org/Zoo-Code/)) - autonomous agent buat VS Code yang bisa baca, edit, dan jalanin perintah sendiri, alternatifnya ada Zoo Code.
- [OpenHands](https://www.openhands.dev/) ([GitHub](https://github.com/All-Hands-AI/OpenHands)) - coding AI open source yang bisa planning, eksekusi perintah, dan beresin task software end to end.
- [Cursor](https://cursor.com/) ([Reset](https://github.com/ultrasev/cursor-reset) / [VIP](https://github.com/kingparks/cursor-vip) / [Help](https://github.com/yuaotian/go-cursor-help)) - coding AI berbasis editor yang jago autocomplete, refactor, dan ngobrol soal kode langsung di file.
- [GitWit](https://gitwit.dev/) - coding AI ringan buat bantu nulis, review, dan rapiin kode langsung dari browser.
- [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) - harness coding AI open source dari DeepSeek buat jalanin agent coding dengan workflow sendiri.
- [Google Antigravity](https://antigravity.google/) ([Add Skills](https://github.com/sickn33/antigravity-awesome-skills) / [Usage Tracker](https://open-vsx.org/extension/crsx/ag-usage)) - coding AI dari Google berbasis Gemini 3 dan Claude Opus 4.6 dengan limit reset mingguan, enak buat vibe coding.
- [AI SDK](https://ai-sdk.dev/) ([GitHub](https://github.com/vercel/ai)) - toolkit coding AI dari Vercel buat bangun aplikasi dan agent AI dengan API yang simpel.
- [Open Interpreter](https://github.com/OpenInterpreter/open-interpreter) - local code interpreter open source yang jalan di mesin sendiri tanpa signup dan bisa eksekusi kode langsung.
- [Code Web Chat](https://codeweb.chat/) ([GitHub](https://github.com/robertpiosik/CodeWebChat)) - coding AI yang bisa dipakai tanpa signup dan nyambung ke VS Code buat tanya dan edit kode.
- [Supermaven](https://supermaven.com/) - tab completion coding AI yang cepat dan bisa dipakai tanpa signup, cocok buat ngebut nulis kode.
- [Qodo](https://www.qodo.ai/) - coding AI buat bantu review, testing, dan rapiin kode biar lebih aman saat merge.
- [OpenChamber](https://openchamber.dev/) ([GitHub](https://github.com/openchamber/openchamber)) - coding AI buat bantu ngoding, riset, dan otomasi tugas langsung dari satu tempat.
- [ZCode](https://zcode.z.ai/) ([GitHub](https://github.com/zai-org/ZCode)) - coding AI dari Zhipu buat bantu nulis dan beresin kode langsung di workflow developer.
- [Ampcode](https://ampcode.com/) - coding AI buat bantu nulis, refactor, dan debug kode langsung di editor.
- [FreeBuff](https://freebuff.com/) - coding agent cloud sandbox berbasis MiMo 2.5 yang enak buat coba task coding tanpa setup lokal.
- [jcode](https://jcode.sh/) - terminal coding agent yang ringan buat bantu nulis dan edit kode langsung dari CLI.
- [Pi](https://pi.dev/) ([GitHub](https://github.com/earendil-works/pi)) - terminal coding agent open source yang simpel dan enak buat automasi coding ringan.
- [omp](https://omp.sh/) ([GitHub](https://github.com/can1357/oh-my-pi)) - terminal coding agent open source yang asyik buat yang suka workflow keyboard dan CLI cepat.
- [cmux](https://cmux.com/) ([GitHub](https://github.com/manaflow-ai/cmux)) - terminal coding agent plus emulator macOS yang cocok buat multitasking coding ala agent.
- [Poolside](https://docs.poolside.ai/api/overview) - coding AI API buat bangun fitur dan workflow coding otomatis di aplikasi sendiri.
- [getdesign.md](https://getdesign.md/) - kumpulan design system yang AI-ready biar hasil coding UI lebih rapi dan konsisten.

## AI Agents

> Catatan: banyak agent jalan dengan akses root dan bisa ubah file plus eksekusi perintah tanpa izin, jadi jangan kasih akses full drive dan idealnya jalan di container, VPS, atau VM.

- [Hermes Agent](https://hermes-agent.nousresearch.com/) ([Docs](https://hermes-agent.nousresearch.com/docs)) - general purpose agent buat eksekusi tugas otomatis, baca dulu docsnya biar setupnya aman.
- [OpenClaw](https://openclaw.ai/) ([Docs](https://docs.openclaw.ai/)) - general purpose agent open source yang bisa integrasi banyak tool, jalanin di sandbox biar aman.
- [Goose](https://goose-docs.ai/) - general purpose agent lokal yang ringan buat otomasi tugas coding dan harian.

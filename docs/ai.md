# AI

Kumpulan tool AI yang kepakai bareng: chatbot gratis, setup ringan, dan trik biar hasilnya maksimal.

## Chatbot

- [DeepSeek](https://chat.deepseek.com/) ([GitHub](https://github.com/deepseek-ai)) - chatbot AI gratis unlimited berbasis DeepSeek-V4.1-Flash yang perlu signup, bisa ditambah fitur via [Better DeepSeek](https://github.com/EdgeTypE/better-deepseek/).
- [Qwen Studio](https://chat.qwen.ai/) ([GitHub](https://github.com/QwenLM)) - chatbot resmi Alibaba berbasis Qwen dengan mode thinking dan agent, multimodal, dan konteks hingga 1M token buat coding, riset, dan dokumen.
- [Z.ai](https://chat.z.ai/) ([GitHub](https://github.com/zai-org)) - chatbot dan agent Zhipu berbasis GLM-5.3/Flash buat coding agentic, visual coding, slides, dan dokumen dengan konteks panjang multimodal.

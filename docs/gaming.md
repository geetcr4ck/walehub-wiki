# Gaming

Kumpulan link gaming pilihan member: referensi main, tools, dan situs unduh game yang kepakai bareng.

## Unduh game

> Catatan: banyak file host pasang tombol unduh palsu yang redirect ke halaman berbahaya, jadi pakai uBlock Origin full dan hanya klik unduh yang jalan di halaman yang sama, bukan yang buka tab baru.

- [AnkerGames](https://ankergames.to/) - situs unduh dan torrent game pre-installed yang perlu signup dengan jatah 7 unduhan bulanan.
- [SteamRIP](https://steamrip.com/) - unduh game pre-installed dengan password `steamrip.com`, simpel tanpa signup.
- [AstralGames](https://astralgames.net/) - unduh game pre-installed lengkap dengan achievements, gampang dipakai.
- [Kryoto](https://kryo.to/) - unduh game pre-installed yang ringan dan minim ribet.
- [GOG Revived](https://gog-rev.com/) - unduh dan torrent khusus game GOG, cocok buat kolektor DRM free.
- [GameBounty](https://gamebounty.world/) - unduh game pre-installed lengkap dengan achievements.
- [Online Fix](https://online-fix.me/) - unduh dan torrent game multiplayer dengan password `online-fix.me`, situsnya bahasa Rusia jadi siapin translator.
- [ZeiGames](https://zeigames.com/) - unduh game pre-installed plus multiplayer, wajib pasang adblock sebelum buka.
- [Ova Games](https://www.ovagames.com/) - unduh game dengan password `www.ovagames.com`, perlu redirect bypass buat lewati shortlink.
- [Torrminatorr](https://forum.torrminatorr.com/) - forum unduh game yang perlu signup, enak buat request dan diskusi rilis.

### Repack game

> Catatan: repack itu versi kompres game yang tukar unduhan kecil dengan install lama, cocok buat bandwidth pas-pasan atau kuota terbatas.

- [FitGirl Repacks](https://fitgirl-repacks.site/) ([Launcher](https://github.com/CarrotRub/Fit-Launcher/) / [Extractor](https://fitgirl-download-link-extractor.vercel.app/)) - repack legendaris via unduh dan torrent lengkap sampai ROM, kompresi paling kecil tapi install paling lama.
- [KaOsKrew](https://kaoskrew.org/) - repack via unduh langsung yang perlu redirect bypass buat lewati shortlink.
- [DODI Repacks](https://www.1337x.to/sort-search/dodi/seeders/desc/1/) ([Peringatan situs](https://github.com/geetcr4ck/walehub-wiki/blob/main/docs/.vitepress/notes/dodi-warning.md)) - repack via torrent yang perlu redirect bypass, baca dulu peringatan situsnya sebelum unduh.
- [Elamigos](https://elamigos.site/) - repack via unduh langsung yang simpel tanpa ribet.
- [Xatab Repacks](https://byxatab.com/) - repack via torrent, situsnya bahasa Rusia jadi siapin translator.
- [Gnarly Repacks](https://rentry.co/gnarly_repacks) - repack via unduh langsung dengan password `gnarly`.
- [M4CKD0GE Repacks](https://m4ckd0ge-repacks.site/) - repack via unduh langsung yang update-nya rajin.
- [VHSTaPE](https://vhstaperepacks.com/) - repack via unduh langsung, alternatifnya ada [Stevv Game](https://www.stevvgame.com/).
- [Spinneret Repacks](https://spinneretrepacks.qzz.io/) - repack via unduh langsung yang ringan.
- [PM2G Repacks](https://rentry.co/pm2gsrepackindex) - repack via unduh langsung dengan password `pm2g`.
- [Vanya Games](https://vanya-games.site/) - repack via unduh langsung yang simpel.
- [Dyren Repacks](https://repacksby.dyren.lol/cb.html) - repack via unduh dan torrent.

## Tools & referensi

- [VGMaps](https://vgmaps.de/) - arsip peta game lama dan baru buat cek jalur, lokasi rahasia, atau nostalgia.
- [Vanilla RTX App](https://github.com/cubeir/Vanilla-RTX-App) - aplikasi all-in-one buat pasang ray tracing di Minecraft Bedrock, dari install Vanilla RTX, ubah texture jadi RTX, tuning pack, sampai launch game langsung.

### Pelacak rilis & info main

- [Library of Codexes](https://libraryofcodexes.com/) - koleksi codex game buat baca lore dan panduan main.
- [r/CrackWatch](https://www.reddit.com/r/CrackWatch/), [r/RepackWorld](https://reddit.com/r/RepackWorld), [IsItCracked](https://isitcracked.com/), [GameStatus](https://gamestatus.info/) - pantau status crack dan rilis scene game terbaru.
- [HowLongToBeat](https://howlongtobeat.com/) ([mirror](https://hl2b.com/)) - cek estimasi durasi tamat game dari data pemain.
- [r/tipofmyjoystick](https://www.reddit.com/r/tipofmyjoystick/) - cari judul game yang lupa dari screenshot atau deskripsi.
- [PSNProfiles](https://psnprofiles.com/) - lacak trofi dan intip profil PSN.
- [Wiki.gg](https://wiki.gg/wikis/) ([Redirector](https://support.wiki.gg/wiki/Redirect_to_wiki.gg)) - kumpulan wiki game yang bersih tanpa iklan berat.
- [Gog To Free](https://greasyfork.org/en/scripts/481134) - userscript yang nambahin link alternatif di halaman toko GOG.
- [r/CrackSupport](https://reddit.com/r/CrackSupport) - tempat diskusi dan tanya jawab soal crack game.

### Remote & cloud gaming

- [Sunshine](https://app.lizardbyte.dev/Sunshine/) ([GitHub](https://github.com/LizardByte/Sunshine)) atau [Apollo](https://github.com/ClassicOldSong/Apollo) - server streaming mandiri buat main jarak jauh via Moonlight.
- [Moonlight](https://moonlight-stream.org/) ([GitHub](https://github.com/moonlight-stream)) - client remote desktop yang mulus buat main game jarak jauh.
- [Greenlight](https://github.com/unknownskl/greenlight) - client alternatif yang lebih enak buat main Xbox Cloud Gaming.
- [Better xCloud](https://better-xcloud.github.io/) ([GitHub](https://github.com/redphx/better-xcloud)) - tambah fitur dan tweak biar main xCloud lebih nyaman.

### Arsip & sejarah

- [The Playstation Datacenter](https://psxdatacenter.com/) - indeks data lengkap konsol Playstation.

- [Archiverse](https://archiverse.pretendo.network/) - arsip Miiverse Nintendo yang sudah tutup.
- [CSDb](https://csdb.dk/) atau [GB64](https://gb64.com/index.php) - arsip dan info lengkap Commodore 64.
- [Awesome J2ME](https://github.com/hstsethi/awesome-j2me) - kumpulan resource dan translator game J2ME.
- [Shmuplations](https://shmuplations.com/) - arsip terjemahan wawancara developer Jepang.
- [ConceptArt](https://vk.com/conceptart) - galeri concept art game.

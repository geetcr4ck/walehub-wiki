# Gaming

Kumpulan link gaming pilihan member: referensi main, tools, dan situs unduh game yang kepakai bareng.

## Unduh game

> Catatan: banyak file host pasang tombol unduh palsu yang redirect ke halaman berbahaya, jadi pakai uBlock Origin full dan hanya klik unduh yang jalan di halaman yang sama, bukan yang buka tab baru.

- [AnkerGames](https://ankergames.to/) - situs unduh dan torrent game pre-installed yang perlu signup dengan jatah 7 unduhan bulanan.
- [SteamRIP](https://steamrip.com/) - unduh game pre-installed dengan password `steamrip.com`, simpel tanpa signup.
- [AstralGames](https://astralgames.net/) - unduh game pre-installed lengkap dengan achievements, gampang dipakai.
- [Kryoto](https://kryo.to/) - unduh game pre-installed yang ringan dan minim ribet.
- [GOG Revived](https://gog-rev.com/) - unduh dan torrent khusus game GOG, cocok buat kolektor DRM free.
- [GameBounty](https://gamebounty.world/) - unduh game pre-installed lengkap dengan achievements.
- [Online Fix](https://online-fix.me/) - unduh dan torrent game multiplayer dengan password `online-fix.me`, situsnya bahasa Rusia jadi siapin translator.
- [ZeiGames](https://zeigames.com/) - unduh game pre-installed plus multiplayer, wajib pasang adblock sebelum buka.
- [Ova Games](https://www.ovagames.com/) - unduh game dengan password `www.ovagames.com`, perlu redirect bypass buat lewati shortlink.
- [Torrminatorr](https://forum.torrminatorr.com/) - forum unduh game yang perlu signup, enak buat request dan diskusi rilis.

## Tools & referensi

- [VGMaps](https://vgmaps.de/) - arsip peta game lama dan baru buat cek jalur, lokasi rahasia, atau nostalgia.
- [Vanilla RTX App](https://github.com/cubeir/Vanilla-RTX-App) - aplikasi all-in-one buat pasang ray tracing di Minecraft Bedrock, dari install Vanilla RTX, ubah texture jadi RTX, tuning pack, sampai launch game langsung.

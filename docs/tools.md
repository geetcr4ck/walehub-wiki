# Tools

Kumpulan web tools yang sering kepakai harian: unduh media, bikin QR, sampai buka aplikasi lewat keyboard. Semua dibuka lewat browser, tidak perlu install kecuali disebut.

## Unduh media

- [Billoxd Method](https://method.billoxd.site/) - panduan setting upload TikTok yang diklaim bikin kompresi lebih ringan, hasil tiap video bisa beda jadi cek sendiri.
- [Popify](https://popify.cc/) - unduh lagu Spotify dalam pilihan format FLAC, AAC, OGG, atau MP3, perhatikan aturan hak cipta tiap lagu.

## Kompres media

- [CompressO](https://compresso.codeforreal.com/) ([GitHub](https://github.com/codeforreal1/compressO)) - aplikasi desktop open-source lintas-platform untuk kompres video dan gambar offline berbasis FFmpeg, lengkap dengan batch, trim/crop/rotate, konversi format, dan tool GIF.

## PDF online

> Catatan: tool client-side proses file langsung di browser jadi dokumen tidak diupload ke mana pun, sementara server-side upload file ke server mereka.

- [ihatepdf](https://www.ihatepdf.cv/) - toolkit PDF client-side yang jalan full di browser, aman buat dokumen sensitif.
- [BentoPDF](https://bentopdf.com/) ([GitHub](https://github.com/alam00000/bentopdf)) - toolkit PDF client-side yang open source, alternatifnya ada [File PDF](https://filepdf.net/).
- [BreezePDF](https://breezepdf.com/) - toolkit PDF client-side yang ringan buat merge, split, dan kompres cepat.
- [PDFKing](https://pdfking.app/) - toolkit PDF client-side dengan tampilan simpel buat olah PDF harian.
- [PDFCraft](https://pdfcraft.devtoolcafe.com/) ([GitHub](https://github.com/PDFCraftTool/pdfcraft)) - toolkit PDF client-side yang open source buat convert dan edit ringan.
- [itinypdf](https://itinypdf.com/) - toolkit PDF client-side yang minimalis buat tugas kecil cepat.
- [PDFWix](https://pdfwix.com/) - toolkit PDF client-side buat merge, split, dan kompres tanpa upload.
- [DigiPDF](https://digipdf.app/?lang=en_US) ([Codeberg](https://codeberg.org/ladigitale/digipdf)) - toolkit PDF client-side yang open source dan bebas iklan.
- [Sejda](https://www.sejda.com/) - toolkit PDF server-side yang fiturnya paling lengkap buat edit serius.
- [ILovePDF](https://www.ilovepdf.com/) - toolkit PDF server-side yang populer buat merge, split, dan kompres.
- [PDFResizer](https://pdfresizer.com/) - tool server-side buat resize dan crop halaman PDF.
- [PDF2Go](https://www.pdf2go.com/) - toolkit PDF server-side buat convert, kompres, dan proteksi file.
- [DPDF](https://dpdf.com/) - toolkit PDF server-side yang simpel buat tugas cepat.
- [Digiparser](https://www.digiparser.com/free-tools/pdf) - tool PDF server-side gratisan buat convert dan ekstrak data.

### PDF offline

- [Stirling PDF](https://stirling.com/) ([GitHub](https://github.com/Stirling-Tools/Stirling-PDF)) - toolkit PDF offline open source buat Windows, macOS, dan Linux yang fiturnya setara web.
- [PDF24](https://www.pdf24.org/) - toolkit PDF gratis buat Windows yang bisa offline, plus versi web bila perlu.
- [PDF4QT](https://jakubmelka.github.io/) ([GitHub](https://github.com/JakubMelka/PDF4QT)) - reader dan editor PDF open source buat Windows dan Linux yang ringan.
- [Foxit](https://www.foxit.com/pdf-reader/) - reader PDF lintas platform yang kencang, hindari installer versi bundle yang bawa software tambahan.
- [xPDFReader](https://www.xpdfreader.com/) - reader PDF minimalis buat Windows, macOS, dan Linux.
- [PDF Arranger](https://github.com/pdfarranger/pdfarranger) - tool open source buat susun, gabung, dan potong halaman PDF di Windows dan Linux.

### Konversi PDF

- [Rare2PDF](https://rare2pdf.com/) - konversi file ke PDF, alternatifnya ada [online2pdf](https://online2pdf.com/) dan [2PDFConverter](https://www.2pdfconverter.com/).
- [Tideflow](https://github.com/BDenizKoca/Tideflow-md-to-pdf) - konverter Markdown ke PDF, alternatif webnya ada [MD2PDF](https://md2pdf.netlify.app/).
- [PDFconvert](https://docupub.com/pdfconvert/) - konverter file PDF buat ubah format bolak-balik.
- [Marker](https://github.com/VikParuchuri/marker) - ubah PDF jadi Markdown yang rapi, enak buat arsip dokumen.
- [PDFCrowd](https://pdfcrowd.com/) - konversi HTML ke PDF atau gambar via API, alternatifnya ada [TailWindPDF](https://tailwindpdf.com/) dan [wkhtmltopdf](https://wkhtmltopdf.org/).
- [Issuu](https://issuu.com/) - ubah PDF jadi flipbook, brosur, dan halaman web yang cantik, plus ada [downloader](https://docdownloader.com/).
- [WebToPDF](https://webtopdf.com/) - simpan halaman web jadi PDF, alternatif open source-nya ada [Percollate](https://github.com/danburzo/percollate).
- [Dangerzone](https://dangerzone.rocks/) ([GitHub](https://github.com/freedomofpress/dangerzone)) - ubah PDF berbahaya jadi file aman dengan sandbox.

## Foto dan visual

- [DOF Simulator](https://dofsimulator.net/) - simulator web buat hitung depth of field dan preview bokeh real-time dari kombinasi kamera, lensa, aperture, dan jarak subjek.

## Streaming

- [Anikage](https://anikage.cc/) - situs streaming anime gratis buat nonton online, lengkap dengan trending, rilisan musiman, dan film.

## Karier & CV

- [Resume Matcher](https://resumematcher.fyi/) ([GitHub](https://github.com/srbhr/Resume-Matcher)) - tool open-source buat tailoring CV, cover letter, dan persiapan interview dari job desc lengkap dengan skor ATS dan export PDF.

## QR dan utilitas

- [Midas QR](https://midasqr.is-local.org/) ([GitHub](https://github.com/Jimm144/midas-qr)) - bikin QR code yang bisa diatur warna dan gaya, cocok buat link atau info WiFi.
- [VidhyaGen](https://vidhyagen.com/) - kumpulan tool web kecil buat olah gambar, PDF, dan teks dalam satu situs.

## Launcher

- [Asyar](https://asyar.org/) ([GitHub](https://github.com/Xoshbin/asyar)) - launcher aplikasi yang dibuka lewat ketikan keyboard, ketik nama app lalu enter.

## Transfer file

- [LocalSend](https://localsend.org/) ([GitHub](https://github.com/localsend/localsend) / [Web Version](https://web.localsend.org/)) - kirim file lokal lintas semua platform tanpa internet, ada versi web buat perangkat yang tidak install app.
- [Blip](https://blip.net/) - kirim file hybrid buat Windows, macOS, Android, dan iOS, matikan Searchable by Name di settings biar tidak gampang ditemukan orang.
- [Photon](https://photondev.netlify.app/) ([GitHub](https://github.com/abhi16180/photon)) - kirim file lokal buat Windows, macOS, Linux, dan Android yang open source.
- [KDE Connect](https://kdeconnect.kde.org/) ([Source Code](https://kdeconnect.kde.org/get-involved.html)) - paket lengkap kirim file lokal plus sinkron notif dan remote HP buat semua platform.
- [Wormhole](https://wormhole.app/) ([GitHub](https://github.com/webtorrent/wormhole-crypto)) - kirim file online langsung dari web dengan enkripsi end to end.
- [Warpinator](https://github.com/linuxmint/warpinator) - kirim file lokal bawaan Linux Mint yang simpel buat Windows, Linux, dan Android.
- [Phone Link](https://www.microsoft.com/windows/sync-across-your-devices) - tool bawaan Windows buat sambung HP Android atau iOS dan kirim file hybrid.
- [Google Quick Share](https://www.android.com/quick-share/) - kirim file hybrid bawaan Android yang nyambung ke Windows dan iOS.
- [Sefirah](https://github.com/shrimqy/Sefirah) - kirim file lokal open source buat nyambungin Windows dan Android.
- [AlterSend](https://github.com/denislupookov/altersend) - kirim file online open source buat Windows, macOS, Linux, Android, dan iOS.
- [QRServ](https://play.google.com/store/apps/details?id=dev.uint.qrserv) ([GitHub](https://github.com/uintdev/qrserv)) - share file lokal dari Android lewat QR code biar cepat dibuka di perangkat lain.
- [Magic Wormhole](https://github.com/magic-wormhole/magic-wormhole) - kirim file online aman pakai kode sekali pakai buat Windows, macOS, Linux, dan Android.
- [croc](https://getcroc.com/) ([GitHub](https://github.com/schollz/croc) / [GUI](https://github.com/howeyc/crocgui)) - kirim file online lewat terminal pakai kode singkat buat semua OS desktop dan Android.
- [LANDrop](https://landrop.app/) - kirim file lokal lintas semua platform tanpa perlu akun.
- [NahrajSoubor](https://new.nahrajsoubor.cz/) - upload dan bagi file online langsung dari web tanpa ribet.
- [IPFS](https://ipfs.tech/) - protokol transfer file desentral buat desktop dan mobile yang tahan sensor.
- [IPFS Tools](https://awesome.ipfs.tech/) ([Extension](https://github.com/ipfs/ipfs-companion) / [Desktop](https://github.com/ipfs/ipfs-desktop)) - kumpulan toolkit IPFS mulai dari extension browser dan app desktop sampai Cluster buat hosting file.
- [aQRoss](https://aqross.app/) - share file via QR code langsung dari web buat Windows, macOS, dan Linux.
- [qrcp](https://qrcp.sh/) ([GitHub](https://github.com/claudiodangelis/qrcp)) - share file via QR code dari terminal buat Windows, macOS, dan Linux.
- [OnionShare](https://onionshare.org/) ([GitHub](https://github.com/onionshare/onionshare)) - share file anonim via jaringan Tor buat semua platform.
- [FileZilla](https://filezilla-project.org/) - client FTP klasik buat Windows, macOS, dan Linux, hati-hati installer bundle yang bawa software tambahan.
- [Sendme](https://www.iroh.computer/sendme) ([GitHub](https://github.com/n0-computer/sendme)) - transfer file via CLI yang simpel, alternatif webnya ada [DashBeam](https://dashbeam.net/).
- [termscp](https://termscp.rs/) ([GitHub](https://github.com/veeso/termscp)) - transfer file dari TUI terminal yang enak buat yang betah di command line.
- [WinSCP](https://winscp.net/eng/index.php) - client FTP klasik khusus Windows.
- [robocopy](https://learn.microsoft.com/windows-server/administration/windows-commands/robocopy) ([WebUI](https://ar-puuk.github.io/robocopy-gui)) - panduan transfer file bawaan Windows yang andal buat copy massal.

### P2P

- [PairDrop](https://pairdrop.net/) ([GitHub](https://github.com/schlagmichdoch/pairdrop)) - kirim file P2P langsung dari web, alternatifnya ada [Snapdrop](https://node-snapdrop.onrender.com/).
- [JustBeamIt](https://justbeamit.com/) - kirim file P2P dari web tanpa daftar, tinggal drag dan bagi link.
- [Surge](https://github.com/rule110-io/surge) - app P2P open source buat kirim file cepat di Windows dan macOS.
- [ToffeeShare](https://toffeeshare.com/) ([GitHub](https://github.com/ToffeeShare)) - bagi file P2P langsung dari web tanpa upload ke server.
- [Station307](https://www.station307.com/) - bagi file P2P dari web yang simpel tanpa install.
- [new.space](https://new.space/) - bagi file P2P dari web yang enak dibuka di iOS.
- [WebWormhole](https://webwormhole.com/) ([GitHub](https://github.com/saljam/webwormhole)) - kirim file P2P terenkripsi dari web buat Windows, macOS, dan Linux.
- [Clip Fish](https://clip.fish/) ([GitHub](https://github.com/clip-fish/web)) - bagi file P2P ringan langsung dari web tanpa daftar.

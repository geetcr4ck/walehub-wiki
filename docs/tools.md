# Tools

Kumpulan web tools yang sering kepakai harian: unduh media, bikin QR, sampai buka aplikasi lewat keyboard. Semua dibuka lewat browser, tidak perlu install kecuali disebut.

## Unduh media

- [Billoxd Method](https://method.billoxd.site/) - panduan setting upload TikTok yang diklaim bikin kompresi lebih ringan, hasil tiap video bisa beda jadi cek sendiri.
- [Popify](https://popify.cc/) - unduh lagu Spotify dalam pilihan format FLAC, AAC, OGG, atau MP3, perhatikan aturan hak cipta tiap lagu.

## Kompres media

- [CompressO](https://compresso.codeforreal.com/) ([GitHub](https://github.com/codeforreal1/compressO)) - aplikasi desktop open-source lintas-platform untuk kompres video dan gambar offline berbasis FFmpeg, lengkap dengan batch, trim/crop/rotate, konversi format, dan tool GIF.

## Foto dan visual

- [DOF Simulator](https://dofsimulator.net/) - simulator web buat hitung depth of field dan preview bokeh real-time dari kombinasi kamera, lensa, aperture, dan jarak subjek.

## QR dan utilitas

- [Midas QR](https://midasqr.is-local.org/) ([GitHub](https://github.com/Jimm144/midas-qr)) - bikin QR code yang bisa diatur warna dan gaya, cocok buat link atau info WiFi.
- [VidhyaGen](https://vidhyagen.com/) - kumpulan tool web kecil buat olah gambar, PDF, dan teks dalam satu situs.

## Launcher

- [Asyar](https://asyar.org/) ([GitHub](https://github.com/Xoshbin/asyar)) - launcher aplikasi yang dibuka lewat ketikan keyboard, ketik nama app lalu enter.
